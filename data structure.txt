class Solution {
    public int numberOfSubarrays(int[] nums, int k) {

        int n = nums.length;
        int count = 0 ;
        int sum = 0;
        Map<Integer,Integer> map = new HashMap<>();
        
        map.put(0,1);

        for(int i = 0 ;i < n ;i++){

            if(nums[i]%2 != 0)
            sum+=1;

            if(map.containsKey(sum - k)){

                count += map.get(sum-k);
            }

            map.put(sum,map.getOrDefault(sum,0)+1);

        }
        return count;
    }
}

🔸 Two Common Conventions (IMPORTANT ⚠️)

There are 2 ways people define height:

1. Height in terms of edges (most used in DSA)
Single node → height = 0
Empty tree → height = -1
2. Height in terms of nodes
Single node → height = 1
Empty tree → height = 0

👉 Always clarify in interview!


public int height(TreeNode root) {
    if (root == null) return -1; // for edge-based

    int left = height(root.left);
    int right = height(root.right);

    return 1 + Math.max(left, right);
}
